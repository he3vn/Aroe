FAQ

Everything you need to know about aroe, the terminal recommender.

How do I install aroe?+

You can clone the repository and build with Cargo (git clone https://github.com/he3vn/Aroe && cargo build --release) or download prebuilt standalone binaries from the GitHub releases page for macOS, Linux, and Windows.

Does it work offline?+

Yes. The entire anime catalog is bundled directly into the application data. Once installed, search, vibe selection, and the recommender engine work completely offline without an internet connection.

Where does the anime catalog come from?+

The offline dataset is powered by the open-source Anime Offline Database (manami-project). When you view rich details, aroe optionally fetches additional synopsis information from AniList and caches it locally.

What terminal emulators are supported?+

aroe runs on any modern terminal emulator with truecolor support, including Ghostty, Alacritty, Kitty, iTerm2, WezTerm, Windows Terminal, and macOS Terminal.app.

How does the recommendation algorithm work?+

It calculates weighted genre and theme vectors based on your ratings (Amazing = +2.0, Good = +1.0, Meh = +0.2, Bad = -1.5) with TF-IDF penalty for ubiquitous tags, era proximity, and type preferences. It is 100% deterministic and runs in microseconds.

Is aroe free and open source?+

Yes. aroe is 100% free and open-source under the MIT license. You can inspect every line of code, modify it, or contribute back on GitHub.
